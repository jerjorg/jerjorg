## Jeremy Jorgensen

Computational physics, Utah Valley University. I work on numerical methods for electronic structure calculations, mainly Brillouin zone integration and k-point sampling in density functional theory.

**[SymmetryReduceBZ.jl](https://github.com/jerjorg/SymmetryReduceBZ.jl)** is my main open-source project: a registered Julia package that computes irreducible Brillouin zones for any 2D or 3D crystal structure. It implements the algorithm from our 2022 paper in *Communications in Computational Physics*.
